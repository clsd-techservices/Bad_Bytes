# Bad Bytes

A daily, deeply unprofessional rundown of what's happening in K-12 IT: Intune, Entra, Verkada, AI, school cybersecurity and whatever else is on the horizon. Hosted by Rocco and Benji, who should not be trusted with Global Admin.

**Listen:** https://clsd-techservices.github.io/Bad_Bytes/
**Podcast feed (add to any podcast app):** https://clsd-techservices.github.io/Bad_Bytes/feed.xml

This repo is published automatically. Episodes are generated each school-day morning by a private build and uploaded as [Releases](../../releases). Please don't edit `docs/` by hand; the next build will overwrite it.

Rocco and Benji are fictional hosts with AI-generated voices.
